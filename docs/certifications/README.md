# AXQuant checkpoint certifications

This directory records public, revision-bound AXQuant checkpoint verdicts. A checkpoint-tier
certificate covers the exact artifact named by its record; it does not promote sibling models,
other revisions, or optional runtime acceleration features.

| Checkpoint | Edition | Tier 1 | Tier 2 MTP acceleration |
| --- | --- | --- | --- |
| [Qwen 3.6 27B AXQ 6-bit](qwen36-27b-axq6-tier1.md) | v3 | Certified | Not certified |

The machine-readable record beside each report is authoritative for thresholds, checksums, and
exact artifact identity. See [flagship certification](../flagship-certification.md) for the
two-tier policy.
