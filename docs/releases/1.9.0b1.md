# AXQuant 1.9.0b1

This is an **experimental toolkit beta**. It is not a certification release and
does not change any public pack, certificate, or 1.8.1 install pin.

## Added

- `axquant diagnose-joint` enumerates a small `(weight BPW × KV bits × context)`
  grid under one memory budget and optionally computes
  `I(W, KV) = ΔQ(W, KV) − ΔQ(W) − ΔQ(KV)` from three bound quality
  evaluations. The report is development evidence only
  (`axquant.joint-interaction.v1`, `certification_eligible=false`).
- Operator notes: [docs/experimental-joint-interaction.md](../experimental-joint-interaction.md).

## Changed

- Package version is `1.9.0b1`. Planning, convert, validate, and
  `verify-cert` paths are unchanged.

## Operator action

- Keep production converts on `axquant[mlx]==1.8.1`.
- Try the diagnostic from a venv that has this branch installed:
  `axquant diagnose-joint --help`.
- Do not cite `joint-interaction.json` as a public quality or speed claim.
  A material `I(W, KV)` only justifies building a real joint planner later.
