### Added

- GPT-OSS 20B/120B conversion through a thin, fail-closed MXFP4-to-affine re-pack path,
  including logical expert reconstruction, bias-sidecar protection, large-convert CPU fallback,
  and a manual no-4-bit 120B agent-coding recipe.
- `compose-gemma4-assistant-mtp` and formal Gemma/Qwen sparse-MoE exact-MTP benchmark profiles
  for assembling and evaluating byte-identical target plus assistant candidates.
- Public checkpoint and scoped MTP-acceleration certificates for exact Qwen 3.6 revisions;
  checkpoint certificates for Gemma-4, Qwen3-Coder-Next, GPT-OSS 6-bit packs, and experimental
  DeepSeek V4 Flash 2/3-bit packs. Certificate scope and negative verdicts remain explicit.
- A generated public certification index and matrices sourced from validated certificate JSON.
- Canonical JSON Schema snapshots, a digest manifest, a generated schema catalog, and CI checks
  that prevent an existing `schema_version` from silently changing meaning.
- Conversion-ladder guidance plus proposed ADR, PRD, and technical specification for future joint
  weight/KV deployment optimization.

### Changed

- Checkpoint Tier 1 and MTP acceleration Tier 2 are modeled and reported as independent claims;
  passing quality, size, and runtime checks no longer implies an acceleration claim.
- Certified model-card preparation resolves claims from the public certificate source of truth,
  verifies the final on-disk manifest digest, and fails closed on mismatches.
- Gemma-4 text preparation strips unused multimodal configuration, supports packed A4B expert
  paths, and synchronizes assistant tokenizers for composite MTP candidates.
- Scoreboards can bind an evaluation profile and independently require prompt-median and scoped
  MTP acceleration gates.
- Nemotron-3-Embed checkpoints can use the promoted Ministral3 preparation path.

### Fixed

- GPT-OSS native MXFP4 expert inventory now counts logical parameters and shapes correctly,
  excludes fused expert biases from quantization, and verifies the post-repack group size.
- Public model-card certificate binding now hashes the finalized artifact manifest.
- Tier 2 certificate lookup binds the intended artifact instead of pairing records by filename.
- Qwen/Gemma sparse-expert module mapping, exact-profile environment handling, and recovery of
  parseable reports after MLX teardown crashes are hardened.

### Notes / operators

- Existing artifact payloads keep their current `schema_version`; this release adds frozen
  contract snapshots and new public-certification envelopes, so no existing artifact migration
  is required.
- GPT-OSS conversion requires an `mlx-lm` build with `gpt_oss`; DeepSeek V4 conversion still
  requires one with `deepseek_v4`.
- The product-default MTP route remains direct fallback. Scoped Tier 2 certificates apply only to
  their exact checkpoint, hardware, workload, runtime, and benchmark contract.
