# AXQuant 1.8.0

## Added

- Published Certification Specification v1.0 and added offline `axquant verify-cert` verification.
  The command emits the strict `axquant.certification-verification.v1` report, checks class-SKU,
  manifest, plan, file-digest, measured-BPW, evidence-kind, and Tier 1/Tier 2 consistency, and exits
  nonzero on any changed binding.
- Added `axquant optimize`, a deployment-planning command that applies one explicit memory limit to
  weights, optional per-layer KV cache, and a visible runtime reserve. It writes the new
  `axquant.deployment-plan.v1` JSON contract plus a Markdown explanation and fails before conversion
  when the requested deployment is infeasible.
- Published the `axq-affine-u32-v1` interchange specification and an MLX-optional conformance helper
  for the unchanged affine U32 pack shared by AX Engine and MLX-LM.

## Changed

- Public claims now use stable `4bit`/`6bit` class-SKU Hub repositories. Measured main BPW is the
  authoritative claim and appears in the model-card heading; the derived `MP-…bpw` string remains a
  display label rather than a repository generator.
- Optimization modes now change recorded objective weights: quality emphasizes task/output
  fidelity, low-memory emphasizes peak-memory cost, and speed emphasizes decode/prefill cost.
  Balanced mode preserves the existing profile objective.
- Added the mechanical 5% complete-weight saving threshold for publishing a distinct 4-bit sibling.
  Existing certified repositories remain unchanged.

## Operator action

- Use `axquant verify-cert --certificate CERT [--artifact DIR]` to produce the machine-readable
  third-party verification report for a local release bundle. Legacy v1 public certificates remain
  readable and are not silently upgraded or rewritten. Historical planning-class labels such as
  `5p6bpw` on a `4bit` Hub SKU still verify.
- Pass an explicit `--max-memory` and `--context` to `axquant optimize`. Its documented reserve
  default is 1 GB; use `--reserve-memory` to bind a different runtime allowance.
- No checkpoint repack, Hub repository rename, or migration of existing plan, manifest, or public
  certificate JSON is required. Install with `python -m pip install 'axquant[mlx]==1.8.0'`.
